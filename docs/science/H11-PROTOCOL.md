## Attribution
Record every call to PredictionEncoderCabac::encode_correction as (category,value), and reference decision features predicted len/dist plus target-is-literal label (label never used as predictor input). Record CABAC payload bytes separately from full bitcode ReconstructionData bytes. For each category replay only its actions into a fresh unmodified CABAC encoder (instrumentation disabled), measure actual isolated encoded size including all category flags and termination. Also replay all categories in original event order and verify payload exact equality. Isolated sizes are NOT additive attribution; report sum and shared overhead. Compute zero-order empirical entropy per category (plug-in, in-sample, not coded size), count and nonzero rate.
## Alternatives
Keep original parameter serialization (bitcode ReconstructionData with empty correction vec). For 17 categories in enum order, serialize a sparse lane: ULEB128 total count, ULEB128 nonzero count, then gap (zeros since preceding nonzero or start), value-1 as ULEB128. Alternative A raw lanes, B zlib level9 over lanes, C XZ5 CRC64 over lanes. Frame u8 backend + u32 parameter blob len + parameter blob + payload. Category order implicit; no event-order transmission. Restore by unpacking lanes and implementing PredictionDecoder that consumes next value of requested category, recreates blocks using original predictor and DeflateWriter, asserts all category queues exhausted; independent byte-exact original raw DEFLATE check for all three. Compare full alternative frame sizes versus original full preflate bitcode blob, sum and per-stream wins. Primary gate: best per-stream of A/B/C (oracle, not deployable selector) <=95% baseline total and >=70/140 strict wins, all streams verified. If fails, do not integrate. Also report per-category isolated CABAC sizes vs counts; no claim exact marginal bit attribution.

Diagnostic loss not actual encoded bytes; H11b: mixture reduces log loss >=5% aggregate and >=3/5 format panels; this only supports a future real conditional coder, not changing token predictor. Predicted length/distance available during original decoder decision. Estimated compressor parameters held fixed; no claim causal effect of compressor strategy.
