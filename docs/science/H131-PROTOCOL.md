# H13.1 — calibration of fast native codecs
Protocol before measurements. Test whether H13 fast/balanced gap survives removing CLI launch and short-input artifacts. No new codec or novelty claim.
Data: full Silesia dickens (10192446), mr (9970564), x-ray (8474240), first 16777216 bytes mozilla (51220480), verify full manifest hashes. New local data: whole /usr/lib/x86_64-linux-gnu/libavcodec.so.60.31.102 (16550936), first 16777216 bytes /usr/lib/x86_64-linux-gnu/libicudata.so.74.2 (30795392). Record full SHA256, slice SHA256; distinct local ELF/data but not blind holdout. No executing source binaries. All 6 samples, 8–16 MiB approximately.
Native single-call profiles: LZ4 raw block LZ4_compress_fast acceleration 1,4; LZ4_compress_HC level 3,9; ZSTD_compress levels -3,-1,1,3,6,9,12; libdeflate gzip levels 1,3,6. Complete experimental native frame: codec magic H131, codec tag u8, original size u32, CRC32 u32, payload. Native decode reads tag and length, verifies CRC32. LZ4 raw block is not LZ4 CLI frame, zstd frame has additional common header, gzip redundant outer CRC. Include all 13 bytes in sizes and CRC calculation in timed operations. Native compression allocates compressor/bound buffer before timer, libdeflate compressor allocation before timer; decode allocates output and libdeflate decompressor before timer; report explicitly as preallocated native kernel timings, not end-to-end. Separate processes for encode/decode, GNU time peak RSS includes input/output/allocator, no subtracting buffers. CLOCK_PROCESS_CPUTIME_ID and monotonic wall around core call and CRC, plus external process wall including I/O. Compare byte equality outside timers. 
CLI calibration: zstd -T1 -1/-3/-9 and lz4 -1, same input, native CLI formats and default checksum behavior (different container/blocks). GNU time CPU and RSS; outer wall including I/O; no direct equality of format expected. Reference size-only XZ5 CRC64 and 7z PPMd5 timestamps off mmt1 one trial per input; verify each. Reference timings diagnostic, not budgets. 
Three repetitions per native and CLI profile per file, seeded random permutation of all 18 profiles within repetition, reset processes, warm OS cache, no cache dropping. 6*18*3+6*2=336 checks. Report medians, relative range (max-min)/median for native CPU/wall and CLI wall, compare both timing boundaries. A/B constraints unchanged H13 (A enc>=20, dec>=50 MiB/s, both <=64MiB; B enc>=5,dec>=20,both <=256MiB). Native primary: sum per-file median CORE WALL, max per-file median RSS, full native frame bytes; CPU and external wall sensitivity separately. CLI calibration separate A/B. For each panel and aggregate choose minimum fixed-profile bytes feasible. Reference min per-file of XZ5/PPMd5 (optimistic oracle, not selector); report gap and also min single reference profile. Gap is not attainable saving. 
Decision: if native A gap relative to per-panel min fixed reference remains >=20% on BOTH panels and median relative wall range <=20%, nominate fast asymmetry as research target (not proof of advantage). If A gap <20% on either panel or noise exceeds threshold, do not proceed directly; examine B with same conditions or recalibrate. No tuning after outcomes. Future candidate must improve size >=5% at matched resources or >=2x throughput at <=101% size and no worse other resources, independent data. 
One CPU affinity, nice+10, lab lock, free disk>=5 GiB, MemAvailable>=1 GiB, RLIMIT_AS2GiB, FSIZE128MiB, timeout 45s/process. Max job 300s; if interrupted preserve partial and do not infer missing points. No system packages changed, no sudo, temporary files cleanup. All versions and binary hashes recorded.
