# H06.2 — предикторы с ограниченными исключениями против FLAC и ALP
Протокол до измерений. Продолжение H06, не заявка на новизну. FLAC и ALP уже используют известные техники предсказания, упаковки и исключений. См. https://xiph.org/flac/documentation_tools_flac.html и https://doi.org/10.1145/3626717.
## Данные
- ECG: PhysioNet MIT-BIH 1.0.0, records 100,101,103 .hea/.dat, проверка двух каналов 212, первые 65536 пар, преобразование 12-bit signed packed в два отдельных int16 LE массива. Не использовать record 208 (SciPy ECG H06). Хеши источников и канонических массивов.
- Speech: Free Spoken Digit Dataset, commit 26eb9aaf76e81b692f806f9140c2d2777410d7a1, recordings/0_jackson_0.wav, 1_nicolas_0.wav, 2_theo_0.wav, 3_george_0.wav, 4_lucas_0.wav, 5_yweweler_0.wav. WAV mono PCM signed16, все отсчёты. Сравнение канонических массивов, не файлов исходных контейнеров, не медицинская интерпретация.
- Float: ALP upstream commit 31ca0ed11c93c99d3f5b5c30e01a3e1c3832d3ce, data/samples/{neon_air_pressure,neon_bio_temp_c,stocks_de,stocks_usa_c,poi_lat,poi_lon}.csv. Первые 1024 числовых строки каждого, parse float64 LE. Три пары по источнику (NEON, stocks, POI); публичные samples ALP — не blind holdout. Новые относительно H06. Synthetic float special bits (0, -0, NaN payload, infinities, subnormals, repeated decimals) только корректность; int16 random/linear только диагностика.
Пропуск любой реальной панели/файла делает соответствующий gate непроверенным. Лимиты загрузки 3 MiB/file, 25s. Исследуются байты, не выполняются данные.
## Контроли
Integer: raw, XZ5 CRC64, Zstd15, FLAC 1.4.3 -8 --no-padding --no-seektable --force-raw-format --endian=little --sign=signed --channels=1 --bps=16 --sample-rate=исходный, декодирование в raw. FLAC контейнер включён целиком. Float: raw, XZ5, Zstd15, entropack-alp 0.2.1 (commit e92a100cc8f330aa9518d1ebe8b98079d7a3d814), полностью сериализованный Compressed::to_bytes и декодирование from_bytes; также ALP+XZ5 и ALP+Zstd15. Независимый Rust-порт с собственным wire format, не официальный C++ ALP; последний clone не уложился в лимит. При отсутствии порта не утверждать сравнительный результат. Для raw/XZ/zstd исходный dtype/длина внешние, для собственных рамок заголовок учтён; это консервативно для кандидата. Сохраняем полные размеры, все проверки.
## Кандидаты
H06.2a integer: 256 слов, модуль 2^16, предиктор order0/1/2/3 с нулевыми начальными условиями отдельно на блок. Остаток ZigZag. Для каждого порядка и ширины b=0..16 упакованные младшие b бит (LSB-first), исключения с ненулевыми старшими битами как position u8 + полный residual u16. Выбрать минимальный сериализованный размер блока (tie lower order, lower width). Заголовок блока order u8,width u8,exception count u16; длина блока выводится из общего n. Рамка magic 4B, n u32, CRC32, backend tag u8; payload либо plain block records, либо XZ5 либо zstd15. Дополнительно фиксированный delta2+byte shuffle+XZ5/zstd15 (тот же заголовок с отдельным magic, глобальное предсказание, без исключений). Oracle по 5 кандидатам диагностический; gate основной family per-array min этих 5 (потолок меню, не селектор): >=5% экономии против per-array min(raw,XZ,zstd,FLAC) на КАЖДОЙ реальной integer панели. 
H06.2b float: блок 256 слов, для k=0..6 преобразовать конечные x с |round(x*10^k)|<=2^53-1 в signed int64, только если обратное деление совпадает побитово. Остальные значения — exceptions position u8 + original uint64 (в т.ч. NaN, -0). В исключениях целое placeholder=0. Для каждого k использовать order0/1/2 на целых (mod 2^64, zigzag), выбрать минимальную ширину для всех остатков, без вторичных integer exceptions. Сериализация k,order,width u8, count u16, packed residuals, exceptions. Также raw block tag k=255 + raw original, выбрать по длине локальной записи. Рамка 13B, backend plain/XZ5/zstd15. Oracle по трём полным представлениям: >=5% экономии на каждой из NEON/stocks/POI относительно min(raw,XZ,zstd,ALP,ALP+XZ,ALP+zstd). Это известные техники; не заявляем novelty. 
## Измерения
Один run, один CPU affinity, nice +10. Каждый полный кандидат/контроль фактически восстановить и сверить байты, сохранять хеши и точные размеры, время wall диагностически. Исключения, порядок, ширина, заголовки включены. Ошибка восстановления остановит опыт. Пиковый RSS не измеряется. Сравнивать нативную скорость с Python нельзя. Даже при pass без новых независимых данных и оригинального ALP нет production GO. Не менять gate после просмотра результатов.
