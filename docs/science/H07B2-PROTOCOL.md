# H07b.2 — независимая панель precompression и специализированный контроль
Протокол до измерений. Цель — проверка точной реконструкции, а не утверждение новизны.

## Контроли
XZ5 CRC64, zstd15 CLI, 7z LZMA2 preset5 (одно имя input.bin, timestamps off), Precomp 0.4.7 официальный Linux x64, https://github.com/schnaader/precomp-cpp/releases/download/v0.4.7/precomp.zip, SHA-256 бинарника 6a5289ba81ea658e8e7984bf32791635f53b8e7cee4aafc26b853c7cd5b018f8. Precomp -cn -opacked.pcf input.bin, код возврата 0 или 2 при существующем PCF; XZ5 над PCF, затем полная обратная распаковка XZ и Precomp -r. Precomp включает preflate 0.3.5; современный microsoft/preflate-rs не считается проверенным. Precomp имеет пометку development/non-commercial; применять только как исследовательский контроль, не распространять бинарник. Ограничить 45s на вызов, 2 GiB адресное пространство, 64 MiB выход. Ошибки сохранять, не выдавать за победы.
## Кандидаты
Обнаружение: PDF эвристика stream+zlib; ZIP/DOCX/XLSX central directory + local header, method 8, raw DEFLATE без шифрования, границы и CRC; PNG только непрерывные IDAT chunks, объединить payload, хранить lengths, восстановить исходные заголовки и CRC, сверить исходный участок. Не извлекать файлы на диск и не исполнять содержимое. Лимит 2 MiB распакованного потока, 16 MiB на файл. Нераспознанное сохранять без изменения.
Exact: все level 0..9 и strategy 0..4, memLevel8, исходное окно 15 или -15. Принимать только точное совпадение. Patch: тот же поиск, для не совпавших по байтам но равных по длине потоков выбрать вариант с минимальным количеством ненулевых байтов XOR(original,recompressed); лексикографическое разрешение равенств. Хранить полный XOR mask вместе с plain, рецепт и метаданные. Это диагностическая проверка ограниченной модели поправок, не preflate. Для каждого кандидата exact и patch выбираем преобразование только если отдельный XZ5 над полной записью меньше XZ5 над raw-записью этого участка. Затем весь поток записей сжимаем единым XZ5. Полный формат H7B2: magic, original length, CRC32, затем XZ; запись raw tag/u32 length/bytes либо recipe tag, wrapper, window mode, level,strategy,u32 plain length,u32 encoded length,u32 chunk count, chunk lengths, plain, XOR (только patch). PNG reconstruct wrapper validates CRC. Все выходы проверяются побайтово. Зависимость от zlib runtime сохраняется; не production.
## Gate
Основной кандидат patch (включает exact); на всех 15 файлах должен иметь суммарный размер <=95% от суммы per-file min(XZ5,zstd15,7z,Precomp+XZ5), минимум 8/15 строгих побед, при полном доступном контроле. Отдельная абляция: exact vs patch, число реально выбранных patch и суммарный размер. Если Precomp не завершился на любом файле, общий gate непроверен, частичные результаты отдельно. Один прогон, CPU/wall и ограниченные измерения; RSS не сравниваем. Не изменять gate после запуска. Никакой интеграции без независимого повторения, современного preflate и проверки совместимости декодера.
