# H15–H17 sequential parse-quality study
Preregistered before measurements. Prior art Ferragina/Nitto/Venturini https://arxiv.org/abs/0802.0835 and Farruggia et al. https://pages.di.unipi.it/rossano/assets/pdf/papers/SODA14.pdf; no novelty claim.
Data: Silesia dickens,mr,ooffice,samba,x-ray,xml, 262144 bytes from offset floor((full_size-262144)*3/5), manifest hash verified. Local /usr/bin/readelf,/usr/bin/objdump,/usr/bin/openssl,/usr/lib/python3.12/ast.py,/usr/lib/python3.12/dis.py,/usr/lib/python3.12/tokenize.py first min(262144,size) bytes, full and slice hashes. Seven existing synthetic files, manifest hashes. Same panel across stages (diagnostic, no blind holdout). No source binary execution.
Fixed candidate graph: each block <=262144 B, exact 4-byte key, last four positions at each byte including inside matches, max distance65535, lengths4..258, all lengths up to longest exact match for each candidate. Greedy nearest tie identical to H14, checked against H14 implementation. All variants use H14 split B serializer and Zstd3 backend, same framing, mode=1, output exact via pinned H14 decoder. For each variant record full compressed bytes, inner bytes, parse counts, literal/match bytes, overlap doubling copy slices; compare same frame D direct block Zstd3 and whole-input Zstd6/9,XZ5 (no outer overhead, strong). 
H15: G greedy vs F fixed additive DP, literals 8 bits, match 32 bits (8 run overhead+8 length+16 distance). Minimize sum on restricted DAG, integer costs 1/256 bit, ties literal then nearest then shorter via strict improvements; this approximates variable run costs and Zstd entropy, NOT bit-optimal for real format. Check computed F score <= G under same weights.
H16: E DP using fixed per-block empirical greedy-token histograms for literal, length-4, low/high distance bytes, KT-smoothed categorical price -log2((count+0.5)/(total+128)), rounded to nearest 1/256 bit; run overhead 8 bits. Histograms are encoder-side scoring only, not transmitted or decoded; same backend and exact frame. Training on same block is explicit, not holdout. Check E surrogate <= G and F under E weights.
H17: W8 and W32 use E price plus 8 or 32 bits per doubling copy slice (same as H14 overlap-safe copy implementation). Primary W8, W32 diagnostic. Compare to E size, copies, literals; check minimized objective <= E. No claim about runtime. All five parses and four direct controls exact checked on 19 files =171 checks. Stages computed in order within each block, comparisons evaluated in order H15/H16/H17 after corpus complete; H17 diagnostic if prior gates fail, never treat stages as independent replicates.
Gates: H15 F <=95% G and <=95% per-file min(Zstd6,9) EACH real panel, >=6/12 strict wins vs direct. H16 E <=97% F and <=95% direct EACH real panel, >=6/12 wins. H17 W8 <=101% E, copy slices <=75% E, literal bytes <=110% E EACH real panel; AND W8 <=95% direct EACH panel for competitive nomination. If proxy-only passes, report as internal tradeoff, not competitive. W32 secondary no gate. All exact, no posthoc tuning.
