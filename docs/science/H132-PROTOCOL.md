# H13.2 — targeted repeated-call calibration
Protocol before smoke/benchmark measurements. H13.1 identified a size gap but failed the 20% timing-range criterion. This experiment retains that criterion; no production codec changes.
Data: Silesia full dickens and first 16 MiB mozilla, verify whole-file SHA-256 against existing manifest. New local VDS samples: whole /usr/lib/x86_64-linux-gnu/libavfilter.so.9.12.100 and first 16 MiB /usr/lib/x86_64-linux-gnu/libx265.so.199. Record full SHA-256 and slice SHA-256. These are diagnostic panels, not a blind representative holdout; no execution of inspected binaries. Missing sources => corresponding gate unverified, no substitution.
Profiles: LZ4 fast acceleration 1, Zstd 3/6/9/12, libdeflate gzip 6. Same 13B H131 magic/tag/size/CRC32 framing as H13.1. XZ5 CRC64 and 7z PPMd5 (1 thread, timestamps disabled) one run/file as size references, byte-exact decode; no reference speed claim.
Implementation: Python ctypes invokes native library functions directly, measures process CPU and monotonic wall of calls including CRC and header writing, small FFI overhead included. Separate process per file/profile/phase/buffer mode. Two warmups, 7 measured consecutive calls. Preallocated output buffer and libdeflate handle retained across calls; allocation-inclusive variant allocates output and libdeflate handle within each timed operation, frees libdeflate handle within timer, releases output buffer after verification outside timer. No reuse of zstd contexts beyond library's one-shot API. Input file loaded before timing. Encode output compared to warmup bytes (outside timer); decoder verifies each result bytewise against source file (outside timer). RSS GNU time for whole worker incl Python, buffers, checks, warmups; not directly comparable with H13.1 C++ RSS. Output hashes stable across both modes. 4 files * 6 profiles * 2 modes * 7 =336 measured exact decode checks, plus 8 reference checks. Warmups not counted. Randomized order of profile/mode pairs fixed per source SHA; encode before decode. 
Resource safety: one CPU affinity, nice+10, lab lock, >=5 GiB disk free, >=1 GiB available RAM, child RLIMIT_AS 2GiB, FSIZE128MiB, timeout 90s/process, bounded jobs; cleanup temporary files only within lab. Record /proc/stat CPU steal counters, loadavg, optional scaling_cur_freq before/after each worker pair; no privileged changes.
Analysis: sum per-file median wall durations, max per-worker RSS, full archive bytes. Robust margin: sum per-file maximum of 7 observed durations; rates from that sum; NOT confidence interval. Median relative range (max-min)/median, IQR/median diagnostic, CPU counterpart diagnostic. A/B unchanged: A encode>=20 MiB/s decode>=50 MiB/s both RSS<=64 MiB; B >=5/20 both <=256 MiB. Primary preallocated; allocation-inclusive separately. Per-panel fixed reference min(XZ5,PPMd5). Nominate A only if >=20% size excess against fixed reference on both panels, median wall relative range<=20% on both panels, and best feasible profile meets speed thresholds also at observed worst-repeat rates. B analogous only if A fails. No posthoc substitution by CPU/IQR or local smoke. No new code architecture if criteria fail; even pass only nomination. 
Local smoke (if VDS blocked): deterministic synthetic sample >=1 MiB, both buffer modes, all six profiles, 1 warmup + 2 measured calls. Verify exact archive equality and decoded bytes; record environment and counts, do not use local timings in primary gate or claim VDS results. Publish blocker if VDS inaccessible.
