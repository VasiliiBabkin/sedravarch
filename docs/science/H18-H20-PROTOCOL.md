# H18–H20 — lossless structural models for public system logs
Preregistered before data download/measurement. Known prior art: log template compression (https://github.com/logpai/logzip), MDL (https://arxiv.org/abs/math/0406077), no novelty claim. 
Data: public Loghub at pinned commit dd61d0952749ee7963bde24220d1be5ede023033, raw URL https://raw.githubusercontent.com/logpai/loghub/<commit>/<family>/<family>_2k.log. Development families HDFS,BGL,Linux,Apache,Spark,OpenSSH. Separate confirmation families Hadoop,OpenStack,Thunderbird,Windows,Android,Zookeeper. Use entire exact bytes, maximum 2 MiB/file; no annotation CSV or private server logs. Verify and record SHA256, source URL, byte/line counts, no substitution for missing. Family-disjoint panels, not blind in statistical sense (public). No tuning between panels. 
H18: B numeric template grouping by exact tuple of static segments from splitting line on ASCII digit runs; preserve original line boundaries and all bytes. C adaptive grouping by sequence of token types (ASCII alphabetic/underscore, digits, all other bytes), plus first two alphabetic tokens as anchors. Within group infer exact constant columns; all differing columns transmitted. Both models include every static byte, variable data and original group sequence; no external dictionary, no normalization. A = raw bytes compressed XZ5 in equal outer frame. Body: varint row and group counts, group row count and field count, field tag (constant/variable), length-prefixed exact constant or variable lane; variable raw lane length-prefixed each value; row order varint group IDs; full outer frame 13 B magic+mode+input length+CRC32 and XZ5 body (CRC64). B uses alternating constant/variable segments; C uses actual inferred constant columns. Record metadata bytes (including variable lane lengths and order separately), raw column bytes and full archive bytes, empirical H0 of group-ID and field tokens diagnostic only (no claim entropy lower bound for individual file).
H19: D = C with deterministic reversible numeric lane choice. Only entire variable columns with canonical ASCII decimal, nonnegative <=2^63-1 (no leading zeros except zero) may use first value ULEB128 and successive signed delta ZigZag ULEB128. Use numeric mode iff its uncompressed lane strictly shorter, otherwise raw. Per-lane mode byte/length included. Compare D vs C, exact byte restoration. No training data or model discarded.
H20: apply unchanged B,C,D on six confirmation families, even if prior gates fail, in that case diagnostic only. Primary C in H18, D H19; no hindsight selection. All representations A,B,C,D checked plus native direct XZ5, Zstd19, 7z PPMd5, 7z LZMA2 mx5 (single thread, timestamps off, input.bin) checked byte-exact; 8×12=96 checks. Compare strong per-file min of four direct controls (oracle, not deployable single codec). Also report best-of A/B/C/D equal-frame oracle diagnostic. No timing/RSS claims. Not a specialized log compressor comparison: Logzip not tested for exact bytes; if gate passes require strong specialized lossless comparator and larger independent corpus before implementation.
Gate H18 dev C<=95% direct oracle AND C<=95% B and >=4/6 strict wins vs direct. H19 dev D<=97% C AND D<=95% direct and >=4/6 wins. H20 fixed D <=95% direct and <=97% C on confirmation with >=4/6 wins, additionally H19 dev gate must pass to nominate. If H18 C passes and C confirmation <=95% direct and <=95% B >=4/6 wins, C separately eligible for next specialized comparison. All exact. No posthoc redefinition.
