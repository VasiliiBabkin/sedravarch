## Полный размер архивов, байт

Git pack включает pack, idx и таблицу отображения имён. В собственных форматах учтены индекс, имена, CRC и все страницы. Сумма CDC-page32 / solid = 5.8103; против non-solid экономия 44.9635%. CDC-page32 улучшает fixed-page32 на 41.4351%, но проигрывает каждому сильному контролю. На синтетических данных unique_raw 1443412 из 1574910 B: даже после CDC точное устранение дубликатов оставляет 91.65% исходных байтов. Дельта-кодеры используют сходство, не ограничиваясь точными совпадениями. Данный опыт не разделяет влияние размера чанков, частоты изменений, независимости страниц и порядка укладки.

## Стоимость выборочного доступа

Доля чтения — сумма логических байтов read() по 12 запросам / (12 × размер собственного архива). Амплификация — сумма декодированных байтов страниц / сумма запрошенных исходных байтов. Приложение каждый раз читает индекс и имеет пустой кеш страниц. Это не измерение физических дисковых операций.

| Семейство | Fixed-page32: чтение / A | CDC-page32: чтение / A | CDC-single: чтение / A |
|---|---:|---:|---:|
| zlib | 21.42% / 1.711 | 38.64% / 2.439 | 16.10% / 1.000 |
| libpng | 16.32% / 1.540 | 39.48% / 2.154 | 18.47% / 1.000 |
| Git | 13.76% / 1.415 | 45.78% / 2.524 | 18.86% / 1.000 |
| Synthetic | 12.19% / 1.381 | 17.34% / 1.894 | 9.23% / 1.000 |

CDC-page32 не проходит ни порог размера, ни оба порога доступа на каждой из трёх реальных семей. CDC-single достигает амплификации 1 благодаря отдельному сжатию каждого уникального чанка, но ещё сильнее проигрывает по размеру. Более компактная упаковка страниц не гарантирует меньшей относительной стоимости доступа.

## Научный вывод
Точная дедупликация сама по себе недостаточна для изученных версий. Снижение доли чтения относительно собственного архива без сопоставимого размера не доказывает практического превосходства. На синтетике даже крупный относительный выигрыш адресуемости не компенсирует более чем десятикратный размер против solid. Никакого production GO.

## Ограничения
Три группы исходников, один файл на версию, всего 36 реальных версий; это не большие архивы целых репозиториев, не слепой holdout. Нет независимых нетекстовых семейств, реального I/O контролей, замеров памяти и fuzzing. Сравниваем конкретный фиксированный Gear CDC и XZ-страницы, не FastCDC как отдельный кодек. Нативная реализация могла бы изменить время, но не исправить разрыв размеров неизменного представления. Декодер предназначен только для доверенных потоков. Основной архиватор не изменён.
