# H12 — conditional arithmetic coding of reference errors
Protocol before measurements. Pinned preflate-rs 0.7.6, same crate SHA-256 and lock as H11. Goal: isolate only entropy channel ReferencePredictionWrong; unchanged token predictor/parameters and other categories. No novelty claim.
Data: H11 diagnostic panel (15 files, 140 detected streams; same hashes/limits), plus NEW already compressed local gzip files not used in H01–H11: text: /usr/share/doc/nginx/changelog.gz, /usr/share/doc/coreutils/NEWS.gz, /usr/share/man/man1/bash.1.gz, /usr/share/info/coreutils.info.gz; binary: /usr/share/doc/fontconfig/fontconfig-user.pdf.gz and /usr/share/doc/icecast2/assets/font/{FiraSans-Regular,FiraSans-Italic,FiraSans-Bold}.eot.gz. These are two screening panels, correlated fonts and system docs, not blind holdout. Single-member gzip, exact header/trailer preserve, verify CRC through zlib, cap original 512 KiB, plaintext 2 MiB, max_chain_length 4096. No substitution if skipped; record hash and reject. No file content executed.
Implementation: reuse H11 trace (baseline replay verified). Replay all original events EXCEPT ReferencePredictionWrong into original CABAC; serialize parameters + new CABAC via original bitcode. Separate binary arithmetic 32-bit E1/E2/E3, Q32768, integer probabilities KT (2n1+1)/(2(n0+n1)+2) quantized floor, clamp 1..32767; no decay, reset each stream. Two candidates L (length buckets 3,4,5–7,8–15,16–31,32+) and M (equal mixture constant and joint length/distance buckets from H11; quantized constituent probabilities, floor average). End flush and zero padding. Decoder reads predicted length and distance BEFORE choosing token; same contexts update after decoded label, no future labels. All other corrections via untouched original CABAC. Format common mode byte (0 original, 1 L, 2 M), candidate additional u32 other-blob length, bitcode params+other CABAC, then binary stream. Original comparisons include its one-byte mode. Each candidate fixed, no posthoc oracle as main. Assert recovered raw DEFLATE exactly, then full original file via same H10-style local-record policy. For each mode use same framing, original plaintext and wrapper, XZ5 CRC64 over full records; strict local XZ5 selection vs raw independently. Full files restored exact, compare direct XZ5 and strong previously verified H07b.2 control on old panel by SHA. For new gzip also compare whole original gzip XZ5 and zstd15 (verify both), and baseline preflate wrapper. 
Gate H12a: fixed L must reduce full correction blob incl mode by >=5% vs mode0 in EACH new panel (text and binary), >=4/8 strict wins, all 8 complete; M diagnostic. H12b: fixed L complete framed files must be >=1% smaller than baseline preflate wrapper on EACH new panel AND >=5% smaller vs per-file min direct XZ5/zstd15 on EACH new panel. Both must pass to justify further study; even then not production GO. Old panel diagnostic. Log per-stream sizes, full archives, hashes, counts, wall encode/decode (includes CLI/verification; diagnostic), peak RSS via GNU time if available (process only, not whole pipeline; report if unavailable). No comparison of speed with CLI competitors. One CPU affinity, nice+10, bounded jobs, no changes to stable or other services. If preflate refuses a stream record and raw fallback, gate unverified. Stop on mismatches. No tuning after measurements.
