Средняя стоимость полосы команд в этой схеме 3.5117 B/команду, включая заголовки XZ; это не нижняя информационная граница. L проигрывает локальному raw-контролю на 13.00%, P на 32.79%. Лишь два L-преобразования выбраны: XLSX headers_footers offsets 5586 (1660→1560 B) и 7405 (500→496 B). Ни одного P. Хранение plaintext вместо литералов здесь не компенсировало цену всех явно заданных совпадений. Причины относительной стоимости конкретных полей match record не изолированы. Это не доказательство, что структурные методы или условное кодирование неэффективны вообще.

## Научный вывод и дальнейшая работа
Зависимость от версии исходного DEFLATE-компрессора устранена на изученных потоках посредством прямой реконструкции кодов Хаффмана, дополнительных битов, границ блоков и padding. Однако передача всех решений неэффективна. Следующий обоснованный вопрос: можно ли предсказывать значительную долю решений по plaintext, кодируя только неопределённость? Такой подход уже применяется preflate-rs (https://github.com/microsoft/preflate-rs). До разработки собственного predictor необходимо получить современный специализированный контроль и изучить его исходный код и распределение ошибок, зарегистрировать новую отличающуюся гипотезу. Не объявлять уже известную архитектуру изобретением.

## Ограничения
Повторно использована H07b.2 screening-панель, не blind holdout. Контроли взяты из прежнего измерения по совпадающим хешам. Измерение компонент с XZ по отдельности содержит служебные расходы, не оценка условной энтропии. Формат использует фиксированные 9-байтные match records до XZ, локальный отбор, не оптимальный предиктор. Нет доказательства оптимальности или совместимости с каждым допустимым RFC1951 потоком, fuzzing, измерений peak RSS или сравнительной скорости. Современный Microsoft preflate-rs не проверен. Декодер только исследовательский, для доверенных данных. Научная новизна не установлена. Main не изменён.

## Воспроизведение
```bash
source ~/sedravarch-lab/bin/env.sh
cd ~/sedravarch-lab
python experiments/h09/h09_deflate_structure.py --lab "$PWD" --out results/h09-reproduction.jsonl
```
Требуется ранее измеренный H07b.2 JSONL и неизменённый скрипт детектора, оба сверяются SHA-256, а также манифест и корпус лаборатории. Временные каталоги загрузок автоматически очищаются.
