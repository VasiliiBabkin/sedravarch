# H01 — предел полезности простых обратимых преобразований
Дата 2026-11-24. Протокол до запуска.

Гипотеза: фиксированное меню обратимых перестановок и разностных преобразований может дать заметный выигрыш относительно XZ/LZMA2 preset 5 на обычных разнородных данных. Это screening, не доказательство новизны (shuffle известен из HDF5).

Кандидаты: identity, byte-shuffle ширины 2/4/8/16, delta modulo 256 с лагом 1/2/4/8/16, delta с лагом w затем shuffle ширины w для w=2/4/8/16. Остаток неполного элемента при shuffle сохраняется без изменений. Всего 14 фиксированных кандидатов. Один байт селектора включён в каждый трансформированный поток, исходный контроль — обычный XZ. При сравнении oracle с identity используется та же надбавка. Каждый кандидат декодируется и сверяется. Python lzma FORMAT_XZ preset=5, стандартная CRC64. Не сравниваем как полноценные архиваторы.

Данные: семь synthetic из лаборатории (development), 11 полных Canterbury, по три неперекрывающихся окна длиной 262144 байта из начала, середины и конца каждого из 12 Silesia (public screening; среднее смещение floor((n-window)/2)). Срезы не представляют полный корпус. Каждый элемент независим для кодера; итоговые размеры суммируются. Никакого обучения. Фиксируем SHA-256 окон, версии, размеры каждого кандидата, CPU и wall для диагностики. Считаем oracle как минимум по 14 кандидатам с селектором; сравниваем с XZ без преобразования/селектора. Отдельно фиксируем лучшие кандидаты по файлам, стоимость перебора.

Критерий: продолжать разработку универсального селектора лишь при >=5% суммарной экономии на КАЖДОЙ из двух публичных панелей; при меньшем выигрыше отклонить широкую гипотезу для данного меню и панелей, но отдельно исследовать классы данных с >=10% локальной экономией. Синтетические результаты не основание для принятия. Если oracle не проходит порог, селектор внутри данного меню его пройти не может при той же схеме кодирования. При успехе требуется новый независимый holdout и отдельный тест цены выбора. Ошибка восстановления — остановить. Ограничение oracle только для выбранного меню и конкретного кодера, не для всех преобразований.
