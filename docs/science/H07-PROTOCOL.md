# H07 — обратимые преобразования PE/ELF и PDF
Протокол до измерений. Две раздельные гипотезы; не заявляем новый универсальный алгоритм.

## H07a: машинный код
Данные: полные /usr/bin/git, /usr/bin/python3, /usr/bin/openssl, /usr/bin/bash на VDS; четыре PE launcher distlib из https://raw.githubusercontent.com/pypa/distlib/master/distlib/{t32,t64,w32,w64}.exe. Файлы никогда не исполняются. SHA-256 и длина каждого. Если какой-либо недоступен — фиксируем неполноту панели.
Контроли: XZ5 CRC64 с LZMA2; XZ5 с целым x86 BCJ; 7z LZMA2 preset 5 и принудительный BCJ2+LZMA2 (если установленный 7z принимает метод). Для 7z одно имя input.bin, timestamps off, mmt=1. В XZ контрольных потоках имени нет. BCJ — известный фильтр, см. https://tukaani.org/xz/man/xz.1.html. 
Эксперимент: извлечь диапазоны исполняемых файловых секций из PE COFF section table (IMAGE_SCN_MEM_EXECUTE), ELF little-endian x86-64/x86 section table (SHF_EXECINSTR); исключить NOBITS и пустые. Проверять границы, непересечение. Разбить файл на секции и промежутки. Каждый участок сжимать независимым XZ5, в варианте section-BCJ только исполняемые участки с фильтром x86 и start_offset=file offset (не виртуальный адрес); диагностический section-plain без фильтра. Рамка H07E: magic 4B, u32 число частей, u32 исходная длина, CRC32, для каждой части u32 length сжатого потока и сами потоки. Все байты учтены. Сравнить сумму размеров section-BCJ против per-file min(plain,whole-BCJ,7z LZMA2,7z BCJ2) по каждой панели ELF/PE. Gate: >=5% экономии на обеих панелях, все 8 файлов и оба контроля 7z доступны. Иначе не продвигать; диагностический split-plain разделяет влияние сегментации и фильтра. 
## H07b: точное восстановление zlib
Данные: /usr/share/doc/shared-mime-info/shared-mime-info-spec.pdf и по одному первому по лексикографическому пути PDF из каталогов 002,003,004,011,013,021,031 репозитория py-pdf/sample-files (получаем список из GitHub tree API, скачиваем по зафиксированному SHA). Лимит 8 MiB на файл. Это открытые тестовые документы, не репрезентативный holdout. Синтетический контроль: три zlib-потока, default compression level 6, fixed strategy level 9, и двухчастный поток с Z_SYNC_FLUSH, на одном и том же детерминированном тексте; обрамить как stream/endstream, только диагностика.
Ищем начало zlib после лексемы stream с LF/CRLF, проверяем zlib header и eof, лимит 8 MiB распакованного потока и 32 MiB суммарно на файл. Это эвристический поиск, не PDF-парсер; не интерпретируем PDF, не извлекаем текст/изображения, не меняем xref, длины или метаданные. Кандидаты рекомпрессии: zlib.compressobj(level=0..9,wbits=15,memLevel=8,strategy=DEFAULT/FILTERED/HUFFMAN_ONLY/RLE/FIXED). Принимать только если байты идентичны исходному zlib-потоку. Неудачные и нераспознанные участки остаются оригинальными. Не считать простое распаковывание и сжатие точным восстановлением.
Контейнер: H07P magic, u32 original size, CRC32, затем XZ5 над записями raw(tag0,u32 len,bytes) либо recipe(tag1,level,strategy,u32 plain length,plain bytes). При декодировании рекомпрессировать, сверить весь файл. Контроль: прямой XZ5, zstd15 (CLI), 7z LZMA2 preset5. Известный более полный preflate-rs https://github.com/microsoft/preflate-rs сохраняет поправки к исходному DEFLATE; попытаться собрать CLI в временной директории, лимит 90s и локальный cargo cache; при невозможности сборки явно отметить отсутствие сравнения, не утверждать превосходство. Gate предварительного отбора: oracle min(recipe,plain control) >=10% экономии суммарно на всех 8 реальных PDF против per-file min(XZ5,zstd15,7z), recipe выигрывает >=4 файла. Без preflate только preliminary screening, не конкурентное преимущество. 
## Измерения
Один прогон, CPU affinity 1, nice +10, полный размер, хеш, проверка декодирования каждого фактически полученного кандидата, время wall/CPU где измеримо. RAM не измеряется; не сравнивать скорость разных реализаций как доказательство. Ограниченные временные файлы, никаких изменений системных конфигураций и стабильного архиватора. Декодеры исследовательские, для доверенных потоков. Ошибка восстановления останавливает опыт. Не менять gate после запуска.
