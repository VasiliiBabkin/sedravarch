Gzip CLI stores filename metadata by default, unlike the prior Python in-memory benchmark; compare current results within this table. XZ and Zstd use one compression thread. v0.3 improves every compressible input versus v0.2 but is slower in all six pack measurements and trails mature codecs on the three real files. No general superiority claim. Smart Dictionary is bounded heuristic parsing, not globally optimal. The added scripts/compare.py is a reusable equivalent harness, not the exact inline script used for these results.
