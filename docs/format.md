# Experimental format v1

All integers are unsigned little endian. Header: eight bytes 53 44 41 52 43 48 01 00 (SDARCH, version 1, reserved zero).

Each record starts with a codec byte. 255 terminates the stream and must be followed by EOF. Otherwise the record contains decoded length (u32), payload length (u32), CRC32/ISO-HDLC of the original decoded bytes (u32), then payload. Decoded length is 1..65536, payload length is 1..decoded length.

Codecs: 0 raw (equal lengths), 1 RLE, 2 LZ, 3 delta + RLE, 4 delta + LZ. RLE is a sequence of nonzero u8 count and u8 value pairs. LZ tokens 0..127 are followed by token+1 literal bytes; tokens 128..255 encode (token & 127)+3 bytes copied from the prior output at a following u16 nonzero backward distance. Overlapping copies are permitted. Delta is modulo 256 subtraction from the previous original byte, initially zero; reverse by cumulative addition. Each block resets the dictionary and delta state.

The decoder rejects invalid lengths, distances, tags, checksums, missing terminators and trailing data, and enforces a caller-provided total output budget. There is no global integrity digest: deletion or reordering of valid blocks is not detected by per-block CRC alone.

## Format v2 (0.2)

Magic is 53 44 41 52 43 48 02 00. Tags 0..4 retain their meaning. Tags 5..9 wrap the corresponding base tag (tag minus 5) with a byte Huffman stream. Payload begins with a u32 intermediate byte length (1..2*decoded length), then a preorder binary tree and symbol codes, packed MSB-first. Tree internal nodes are bit 0; leaves are bit 1 followed by an eight-bit symbol. Each symbol occurs in the tree at most once; maximum 511 nodes and depth 255. Left edge is 0; right is 1. Single-leaf trees consume no symbol bits. Final padding to a byte is zero; extra bytes are rejected. The encoder selects the smallest payload among raw and transformed candidates with and without Huffman. Ties retain the first incumbent candidate.

After 255: total decoded byte count (u64), block count (u64), CRC32/ISO-HDLC of concatenated decoded bytes (u32), then EOF. This detects ordinary missing/reordered blocks and damaged footer; it is not cryptographic authentication. A v2 decoder also accepts v1, with its original weaker integrity guarantees. Library callers must discard partial output on any error; CLI attempts to remove it.

## Format v3 (0.3)

Magic is 53 44 41 52 43 48 03 00. Footer and tags 0..9 remain as in v2. Tag 10 is Smart LZ, 11 is byte delta + Smart LZ, 12 and 13 wrap tags 10 and 11 in the v2 Huffman envelope. Tokens 0..127 represent token+1 literal bytes. Tokens 128..254 encode (token & 127)+3 match bytes with following u16 backward distance. Token 255 is followed by u16 match length (130..65535) and u16 distance. Distance must be nonzero and no greater than decoded bytes already available in the block. Overlap is allowed. Decoded block and intermediate bounds remain unchanged. Encoder searches at most 32 hash-chain candidates per position, uses a one-position lazy match heuristic, and compares all previous candidates as well; this is not globally optimal parsing. Decoder accepts v1/v2 with original tag limits.

## Encoder 0.4 (unchanged wire format v3)

Encoder policy defaults to Gear content-defined chunking: minimum 32768 bytes, hard maximum 65536, final block may be shorter. Starting from zero, update hash = (hash << 1) + GEAR[byte] modulo 2^64; cut at the first eligible position with hash & 32767 == 0 or at the hard maximum. GEAR is deterministic (SplitMix64 sequence seeded with 0x5344415243480004, see src/chunking.rs). Hash resets per chunk. Fixed 65536-byte mode remains available. Chunk boundaries are not part of the decoding contract; all v3 decoders already support variable lengths. No inter-block references yet. CDC is not guaranteed to improve compression; it prepares stable chunk identity for future deduplication.

## Format v4 (0.5)

Magic 53 44 41 52 43 48 04 00. v3 records and footer remain unchanged. Tag 14: exactly two bytes, u16 backward block distance (1..128). Copy the already verified referenced decoded block; its length must equal decoded length. Tag 15: same distance followed by one or more replacement runs, each u16 offset, u16 nonzero length, then length literal bytes. Runs must be ordered, nonoverlapping and within the current block, with no trailing partial record. Copy the base block and apply replacements. Both tags require base depth <4 and assign base depth+1; independent blocks have depth 0. History is the last 128 decoded blocks; forward/self references and missing/evicted bases are invalid. All results are verified by existing block and stream CRC32. Encoder exact identity uses CRC32 as a prefilter plus full byte equality, never checksum alone. Similarity is heuristic: equal-length blocks only, 64 evenly spaced sample positions, at least 48 equal, at most 3 candidates ranked by score then shallow depth and recency. Patch wins only if smaller than current candidate. Exact references are selected before independent encoding for blocks longer than two bytes; ties with a two-byte independent encoding may favor references. Decoder materializes verified blocks, not recursive reconstruction. Retained payload cache <=8 MiB, excluding working buffers and overhead. pack-independent emits v3 without dependencies.

## Multi-file container v1 (0.6)

Separate outer container: eight-byte magic SDAMULT followed by byte 01. Then contiguous complete v4 streams for regular files in index order (directories have no payload). Index at end: u32 entry count, followed by records: u8 kind (0 file, 1 directory), u32 path byte count, UTF-8 relative path bytes separated by /, u64 decoded size, u64 modification Unix seconds (MAX means unavailable), u64 absolute file offset, u64 packed stream length. Directories have zero size/offset/packed length. Parent directories precede children. File extents start at 8, are contiguous, nonoverlapping, and end exactly at the index. Footer: 8 ASCII bytes SDAINDEX, u64 index byte count, u32 CRC32 of index. EOF immediately follows footer. Limits: index 16 MiB, entries 100000, path 4096 bytes, 64 components, 255 bytes per component. No special files, absolute/traversal paths, control characters, Windows-reserved components, or duplicate case-folded (Unicode lowercase) names. Index checks are not cryptographic authentication. Each file is independently encoded with v4; random access does not decompress unrelated streams. Timestamps are informational; no permissions/ownership restoration. No cross-file graph references. Existing single-stream formats v1-v4 remain supported.

## Encoder 0.7

No wire changes. Profiles and thread counts are encoder policies only. Fast omits Huffman and sparse patches; Balanced searches eight dictionary candidates and one sparse patch; Deep retains 0.6 behavior; Extreme also evaluates 128-candidate dictionary outputs and up to eight patches. Independent candidates may be evaluated concurrently in batches of at most eight blocks; history selection and writing are sequential and deterministic. Retained history bound remains 8 MiB, plus bounded per-worker buffers and overhead. No cross-file history or parallel decoding.
