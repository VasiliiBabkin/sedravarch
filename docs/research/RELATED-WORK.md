# Related work

## Information models

- Shannon defines entropy and the coding interpretation of a source with memory. Cross-entropy is the expected length under a different distribution; Kullback and Leibler define the divergence that appears as the difference. [Shannon 1948](https://people.math.harvard.edu/~ctm/home/text/others/shannon/entropy/entropy.pdf) · [Kullback and Leibler 1951](https://doi.org/10.1214/aoms/1177729694)
- Rissanen proposes describing observations via a model description and residual information. SADM scores the serialized model and payload together. [Rissanen 1978](https://doi.org/10.1016/0005-1098(78)90005-5)
- LZ77 copies substrings from prior output. LZMA2 combines LZ matching and range-coded adaptive statistics with explicit chunk/reset handling. PPM interpolates variable-order symbol context through escapes. CTW mixes model trees recursively, while PAQ combines multiple predictive models. v1 rANS is static per payload, with no PPM escapes, CTW mixture or PAQ context mixer. [Ziv and Lempel 1977](https://doi.org/10.1109/TIT.1977.1055714) · [XZ Utils LZMA specification](https://github.com/tukaani-project/xz/blob/master/doc/lzma-specification.txt) · [Cleary and Witten 1984](https://doi.org/10.1109/TCOM.1984.1096090) · [Willems, Shtarkov and Tjalkens 1995](https://doi.org/10.1109/18.382012) · [Mahoney's PAQ implementation and explanation](https://mattmahoney.net/dc/)
- Arithmetic coding refines an interval for successive symbols. Range coding implements a related integer interval coder. ANS uses a single integer state, with rANS applying arithmetic transitions and tANS using precomputed transitions; FSE is a tANS implementation. SADM implements byte-renormalized rANS with fresh normalized frequencies for each payload. [Witten, Neal and Cleary 1987](https://doi.org/10.1145/214762.214771) · [Martin's range encoding implementation notes](https://www.compressconsult.com/rangecoder/) · [Duda, ANS](https://arxiv.org/abs/1311.2540) · [Collet, FiniteStateEntropy](https://github.com/Cyan4973/FiniteStateEntropy)
- Partition Tree Weighting mixes over temporal partitions and base distributions. The implemented segmentation instead chooses one path with explicit block headers; it does not mix partition probabilities. [Veness et al., Partition Tree Weighting](https://arxiv.org/abs/1211.0587)

## Dependencies and redundancy

- REBL combines duplicate suppression and inter-block delta compression. FastCDC provides a fast Gear-based boundary detector. Finesse accelerates resemblance detection by exploiting feature locality, and Odess reduces the cost of feature extraction and indexing. SADM uses fixed-grid multiscale edges and rolling bottom-k sketches with bounded postings. [REBL](https://www.usenix.org/conference/2004-usenix-annual-technical-conference/redundancy-elimination-within-large-collections) · [FastCDC](https://www.usenix.org/conference/atc16/technical-sessions/presentation/xia) · [Finesse](https://www.usenix.org/conference/fast19/presentation/zhang) · [Odess](https://ieeexplore.ieee.org/document/9458911/)
- Hierarchical RLZ selects relationships between references for relative parsing. Dataset versioning studies storage versus recreation trade-offs on dependency graphs. Bicriteria compression treats compressed size and decode cost jointly. These motivate bounding archive depth and measuring selective retrieval. [Hierarchical Relative Lempel-Ziv Compression](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.SEA.2023.18) · [Principles of Dataset Versioning](https://doi.org/10.14778/2824032.2824035) · [Bicriteria Data Compression](https://arxiv.org/abs/1307.3872)
- VCDIFF supports ADD, COPY and RUN with separate instruction, data and address sections and address caching. SADM v1 uses a simpler interleaved copy/add script, with fixed-width operands and no address cache. [RFC 3284](https://www.rfc-editor.org/rfc/rfc3284)

## Structured data

- BCJ translates selected x86 relative branch operands to improve regularity. BCJ2 uses multiple streams that require joint accounting. Selection requires a byte-exact inverse and measured total benefit including side streams. [XZ filter documentation](https://tukaani.org/xz/man/xz.1.html) · [7-Zip SDK BCJ2 implementation](https://github.com/ip7z/7zip/blob/main/C/Bcj2.c)
- DEFLATE admits many encodings of the same decoded bytes. Microsoft preflate-rs models compressor decisions and stores auxiliary corrections to recover the original stream byte for byte. An ordinary decompress/recompress pass is tested separately and has no general identity guarantee. [RFC 1951](https://www.rfc-editor.org/rfc/rfc1951) · [Microsoft preflate-rs](https://github.com/microsoft/preflate-rs)

The research hypothesis is that bounded resemblance search, real byte-cost selection and depth constraints can jointly pay off for versioned inputs with cheap selective decode. No claim of algorithmic novelty or general superiority follows from this implementation.
