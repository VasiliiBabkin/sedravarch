# Проверка SedravArch Desktop на Windows

Проверяемая сборка — предварительная версия 0.8.0-alpha.1. До публикации и получения успешного результата CI готовый EXE не считается доступным.

1. Распаковать ZIP в новый каталог. В комплекте графический клиент SedravArch.exe, sedravarch-cli.exe и README.txt. Сверить SHA-256 ZIP с опубликованным SHA256SUMS.txt. Цифровая подпись пока отсутствует.
2. Запустить SedravArch.exe без прав администратора. Проверить отображение кириллицы, размеры окна и читаемость тёмной темы.
3. Создать тестовую папку с текстовым файлом, бинарным файлом, вложенной папкой, пустой папкой и пустым файлом. Использовать копии, не оригиналы важных документов.
4. На странице «Создание» добавить папку и отдельный файл. Выбрать «Баланс», два потока, сохранить новый .sda вне папки с источниками. Проверить, что интерфейс не зависает, а после завершения открывается оглавление.
5. Проверить поиск по кириллическому имени. Выбрать файл, извлечь в новый путь, сравнить его с оригиналом через Get-FileHash. Затем проверить весь архив кнопкой «Проверить».
6. Распаковать всё. Проверить структуру и побайтовое соответствие файлов, в том числе пустые файлы и папки. Повторить извлечение в уже существующий путь — операция должна быть отклонена, существующие данные не должны измениться.
7. Повторить создание с режимами «Быстрый», «Глубокий», «Максимум» и разным количеством потоков. Проверить открытие старого однофайлового .sda.
8. Во время длительной операции попробовать закрыть обычным способом окно; операция не должна прерываться. Принудительное завершение процесса не является безопасной отменой.
9. Проверить выбор файлов и папок с русскими именами. Зафиксировать версию Windows, сообщение ошибки, точные действия и по возможности снимок окна (без личных данных).

Автоматические headless-тесты не заменяют проверку настоящего окна и системных диалогов. Перед стабильным выпуском требуется ручной PASS по всем пунктам. Не хранить единственные экземпляры важных данных в экспериментальном формате.
